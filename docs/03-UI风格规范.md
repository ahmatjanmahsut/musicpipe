# UI 风格规范 —— 与 DsoMusic（github.com/Moriafly/DsoMusic）同风格

> 依据：DsoMusic app/src/main/res/values/colors.xml（.ref/DsoMusic 已克隆供对照）与项目 README 界面特征。
> 所有颜色/形状/布局 token 如下，Compose 主题必须按此实现；界面文案用中文。

## 2. 形状与材质

- 卡片圆角 12dp；条目圆角 8dp；对话框圆角 16dp；封面圆角 8dp（列表中 4dp 小图）。
- 迷你播放条：贴底、半透明白 + 模糊（RenderEffect 或半透明近似）、上缘 0.5dp 分割线、内部：封面 40dp 圆角4、标题/艺术家两行、红色播放/暂停图标按钮。
- 播放页：DsoMusic 标志性「旋转 CD」——封面圆形裁剪置于浅白圆盘（playerCdBackground）上，播放时匀速旋转（约 20s/圈），暂停停转；点击 CD 切到歌词页，歌词页点击切回。
- 顶栏：白底、标题居中或居左（#050505，16-18sp）、返回箭头图标 #000000。
- 列表条目（歌曲行）：左封面 48dp 圆角4（占位 #F3F3F3 salt_color_song_cover），标题 15sp #050505 单行省略，副标题 12sp #787878（艺术家 · 专辑），右侧更多/心形图标 #5A5A5A。
- 按钮：主按钮填充 #DB2C1F 白字圆角 24dp（胶囊）；次按钮描边 #DB2C1F。
- 图标：Material Icons Outlined 为主，前景 #000000（浅）/#FFFFFF（深），次图标 #5A5A5A。
- 字体：默认系统字体；标题 18sp/中黑，正文 15sp，辅助 12-13sp。

## 3. 页面清单与布局要点（对照 DsoMusic 同名功能）

1. 登录/注册页：大标题「MusicPipe」+ 副标语，居中卡片式表单（输入框 #F5F5F5 圆角 8），红色胶囊主按钮，底部切换登录/注册文字链接（#0470E6）。
2. 主页：顶栏「主页」+ 右侧搜索/设置图标；「猜你喜欢」横向卡片或「随机歌曲」纵向列表；底部 MiniPlayer；抽屉或底栏入口：主页/我喜欢/播放历史/设置。
3. 搜索页：顶部搜索框（#F5F5F5 圆角胶囊），结果歌曲列表（同歌曲行样式）。
4. 播放页：上半 CD 旋转封面（或歌词页），下半：歌曲名 18sp 居中 + 艺术家 13sp #787878、进度条（细线、红色滑块、两端时间 11sp #969696）、控制行：收藏心形（已收藏红色填充）/上一曲/播放暂停（大红圆钮 56dp）/下一曲/歌词按钮；背景：封面主色模糊渐变或纯白。
5. 歌词页：居中标题艺术家，LRC 滚动列表：当前行 #050505 16sp 加粗，其他行 #6C6C6C 14sp，行距 12dp；顶部降级提示条（浅黄底 #FFF7E6 棕字）「未匹配到歌词」仅在无歌词时显示。
6. 播放历史页：列表同歌曲行 + 右侧时间（MM-dd HH:mm，12sp #969696）+ 删除图标；顶栏右侧「清空」文字按钮（红色），清空需确认对话框。
7. 我喜欢页：同歌曲行 + 红心（点击取消收藏，即时从列表移除并 Toast）。
8. 设置页：分组列表（DsoMusic 风格分组卡片）：账号（当前用户、角色徽标、退出登录）、服务器（MusicPipe 地址、Navidrome 地址/账号/连通测试）、更新（检查更新，显示当前版本 vX.Y.Z (versionCode)）、外观（主题：跟随系统/浅色/深色）、关于；admin 用户在「账号」组内显示「用户管理」入口（带盾牌图标）；user 角色不渲染该项。
9. 用户管理页（仅 admin）：列表（用户名+角色徽标：admin 红色/user 灰色），FAB 或顶栏「+」新增，行点击编辑（角色下拉、重置密码），左滑或删除图标删除（确认框）。
10. 更新对话框：标题「发现新版本 vX.Y.Z」、更新说明滚动区、大小、「立即更新」红色主按钮 +「稍后」；下载中显示线性进度与百分比；校验失败/下载失败对话框带「重试」。

## 4. 动效

- CD 旋转：无限循环 20s/圈，暂停时动画停在当前角度。
- 页面切换：Compose 默认淡入滑动即可；歌词当前行切换平滑滚动（animateScrollToItem）。
- 心形收藏：点击缩放弹跳（0.8→1.1→1.0，300ms）。
- MiniPlayer 出现/消失：滑入滑出。

## 5. 深色模式

- 跟随系统（theme_mode=system 默认）；深色下：CD 圆盘 #1E1E1E、MiniPlayer 模糊深底 #B3121212 风格半透明、歌词当前行白色。
