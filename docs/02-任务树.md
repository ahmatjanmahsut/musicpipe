## 任务明细

### T0 契约与环境（Lead，前置，无依赖）
- T0.1 编写 01-架构与API契约.md、03-UI风格规范.md、02-任务树.md。
- T0.2 安装工具链到 .tools/（JDK17、Gradle 8.11.1、Android SDK platform-35 + build-tools 35.0.0）。
- T0.3 git init，.gitignore（排除 .tools/ .ref/ node_modules/ build/ data/），初始提交。
- 验收：文档齐备；java -version / gradle -v / sdkmanager --list 可用；git log 有初始提交。

### T1 服务端 musicpipe-appservice（subagent: aa1/workbuddy/glm-5.3-flash，写域 server/**）
- 依赖：T0.1（契约）。与 T2-T6 并行。
- 内容：按契约 §3 实现 Fastify 服务：db 初始化与 migration、scrypt 密码、session cookie 鉴权钩子、
  auth 路由、users 管理路由（admin 门禁）、更新服务（multipart 上传/MD5/流式下载/X-Apk-Md5）、
  歌词路由（可插拔 LyricProvider + data/lyrics 目录默认实现）、system/status、静态托管 web/dist（存在时）。
- 附加：src/mock/subsonic.ts —— 供集成测试的 Mock Navidrome（实现契约 §4 全部端点，含 2 首内置歌曲、
  合成音频流、封面 PNG、内嵌 LRC），可用 MOCK_SUBSONIC=1 与主服务同进程启动（端口 4533 或 PORT_SUB）。
- 测试（test/*.test.ts，node:test + fetch）：
  * auth：首注册=admin；重名409；登录错密码401；无会话访问受保护接口401；me/logout。
  * users：user 访问403；admin CRUD；删自己400；最后admin降级409/删除409。
  * update：admin 上传 apk（含非 apk 拒绝400、重复 versionCode 409）；latest 字段与 md5 正确；
    普通用户可下载、下载字节与上传一致、X-Apk-Md5 正确；无发布404。
  * lyrics：命中/未命中404。mock subsonic：ping/stream/getLyricsBySongId/search3 正常。
- 验收标准（Lead 复跑）：npm install 成功；npm run build 无错误；npm test 全绿；
  手动冒烟：启动后 POST register/login → cookie → GET latest 404 no_release → 上传 → latest 200。

### T2 Android 脚手架（Lead 亲自，写域 app/**，T3/T4/T6 的前置）
- 内容：settings.gradle.kts、build.gradle.kts（根+app）、gradle wrapper、AndroidManifest（权限/FileProvider/PlaybackService）、
  主题（DsoMusic 风格 Color/Theme/Type/Shape）、导航图（含 admin 条件路由）、AppContainer 手动 DI、
  网络层（Retrofit×2：MusicPipe REST 带持久化 CookieJar；Subsonic 带 token/salt 拦截器）、
  Room（ entities/DAOs/database 按契约 §5）、DataStore 封装、域模型、全部 Screen 的占位 composable、
  工具类（Md5、LrcParser 骨架、版本比较）。
- 验收：./gradlew assembleDebug 在脚手架状态即可通过（占位屏可编译），为并行开发提供稳定基座。

### T3 Android 认证 + 用户管理 UI（subagent: aa1/workbuddy/space-bunny，写域 app/.../ui/auth、ui/admin、data/repo 中 AuthRepo/UserRepo 实现文件）
- 依赖：T2。
- 内容：LoginScreen/RegisterScreen（表单校验、错误提示、记住会话）；AuthViewModel（登录态 StateFlow、
  启动时 me() 自动恢复会话）；AdminUsersScreen（列表分页、新增对话框、编辑角色/密码、删除确认）；
  角色权限：导航图中 user_management 路由与抽屉/设置入口仅当 role==admin 时注册与显示（彻底移除，非置灰）；
  角色变更后立即生效（登出/被降级后弹出管理页并回到主界面）。
- 验收：编译通过；单元测试（角色路由过滤逻辑）；Lead review：grep 确认无 admin 判断外的入口残留；
  集成测试用 MockWebServer 验证登录失败/成功分支。

### T4 Android 播放器 + 历史 + 收藏（subagent: aa1/workbuddy/deepseek-v4.1-flash，写域 app/.../service、ui/player、ui/history、ui/favorite、ui/home、data/repo 中 PlayerRepo/HistoryRepo/FavoriteRepo 实现文件）
- 依赖：T2。
- 内容：PlaybackService（MediaSessionService + ExoPlayer，通知控制，音频焦点）；播放队列与 MediaItem 构建
  （Subsonic stream.view URL 拼装）；HomeScreen（随机歌曲/专辑列表 + 搜索）；PlayerScreen（旋转 CD 封面、
  进度条、上下曲、播放/暂停、收藏心形、歌词页切换）；MiniPlayer（底部模糊条）；
  HistoryRepo：播放开始即写入 Room（同曲更新 playedAt 置顶），HistoryScreen（列表/单条删除/清空确认/重启不丢）；
  FavoriteRepo：收藏/取消收藏/我喜欢列表（Room 本地，离线可看，Coil 磁盘缓存封面）；scrobble 上报。
- 验收：编译通过；LrcParser 之外的纯逻辑单测（队列、版本无关）；Lead 集成冒烟：App 对 Mock Subsonic 拉列表/建流 URL 正确。

### T6 Android 歌词 + 更新 + 设置（subagent: aa1/qodercn/qwen3.8-flash，写域 app/.../ui/lyrics、ui/update、ui/settings、data/repo 中 LyricsRepo/UpdateRepo 实现文件）
- 依赖：T2。
- 内容：LrcParser（[mm:ss.xx] 多标签解析、排序、纯音乐/无效文本判定）；LyricsViewModel（position 订阅→
  当前行高亮）；LyricsScreen（同步滚动居中、当前行放大红色高亮、降级提示条「未匹配到歌词」不影响播放）；
  歌词获取链：Subsonic getLyricsBySongId → getLyrics(artist,title) → /api/lyrics/search → 降级；
  UpdateRepo（latest 比对/OkHttp 下载进度/MD5 校验/FileProvider 安装 Intent/未知来源引导/失败重试/文件复用）；
  UpdateDialog + 下载进度 UI；SettingsScreen（服务器地址、Subsonic 账号与连通测试、检查更新、主题切换、
  关于、退出登录、admin 的用户管理入口）。
- 验收：编译通过；LrcParser/Md5/版本比较 单测全绿；更新流程在 Mock 服务下 E2E（下载→md5→intent 构造）。

### T5 Web 管理页（subagent: aa1/qodercn/qwen3.8-flash 第二批，写域 web/**）
- 依赖：T0.1。与 T1 并行开发，联调需 T1 完成。
- 内容：Vue3+Vite+Element Plus：登录页、用户管理页（增删改查+角色分配，仅 admin 可见路由）、
  发布管理页（上传 APK：versionName/versionCode/changelog + 文件；列表；删除；显示 MD5/大小）、axios 带 cookie、
  401 跳登录、403 提示。构建产物 web/dist 由 server 托管。
- 验收：pnpm build 成功；Lead 用浏览器自动化或 HTTP 冒烟：登录→上传 apk→列表可见→App latest 接口返回一致。

### T7 集成构建与修复（Lead，依赖 T1-T6）
- server：npm install/build/test 全绿；web：build 产物进 server 静态目录；app：gradlew assembleDebug 出 APK；
  编译错误由 Lead 修复或打回对应 subagent（send_message 精确指令）。
- 验收：三端构建全通过，产出 app/build/outputs/apk/debug/app-debug.apk。
